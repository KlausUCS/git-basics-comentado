## Comandos desta seção (2)

### 1. `git init [nome-do-projeto]`

```bash
git init [nome-do-projeto]
```

**O que faz:**

Cria um repositório Git dentro da pasta.

**Quando usar / observação:**

Quando começar um projeto do zero usando Git.

---

### 2. `git clone [url]`

```bash
git clone [url]
```

**O que faz:**

Baixa uma cópia do repositório que já existe.

**Quando usar / observação:**

Quando pegar um projeto do GitHub, pra começar a trabalhar nele no meu computador.
Ele já cria a pasta do projeto e configura a ligação com o repositório remoto.
